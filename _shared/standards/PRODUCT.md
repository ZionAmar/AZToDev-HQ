# Product Standards

Guided by company motto: **Build truth. Ship value. Scale leverage.**  
See `_company/MOTTO.md` — every project must answer the 6 mantra questions.

- Every feature has: user, problem, AC, metric, edge cases
- v1 = thinnest path to learning/value (Smallest True Slice)
- Analytics events named in PRD before build
- Non-goals are mandatory — what we refuse to build this round
- Never market what the product cannot keep (Trust Is the Product)
