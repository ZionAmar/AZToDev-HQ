# Founder channel ledger

Git-tracked copy of the Telegram thread between ציון and נועה (plus specialist background updates).

**Why:** `ops/runtime/` is gitignored and dies on every Cloud VM. Without this file, Cloud Noa could not see Nadav reports that already reached Telegram — and reopened the same Linear phases.

**File:** `ledger.jsonl` — one JSON object per line: `{ at, role, text, source }`.

**Roles:** `founder`, `noa`, `system`, or agent id (e.g. `34-pc-ops`).

**Rule for נועה:** Before opening a phase or Linear issue, read recent ledger entries. If the deliverable already appears here, advance — do not re-delegate the same step.
