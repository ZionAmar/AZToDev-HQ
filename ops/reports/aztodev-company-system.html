03 זרימת הודעות טלגרם

כל הודעה מסווגת לנתיב: consult (שיחה), execute (ביצוע), או status (סטטוס חי). WIP=1 — משימה אחת פתוחה; החברה זוכרת בקשות חוזרות.

consult · chat

ייעוץ / שיחה

שאלות קצרות, «מה דעתך», רק לחשוב בקול — לא ביצוע.

  • Fast desk LLM (GPT mini)
  • Keep / Defer / Kill
  • תשובה מיידית, בלי Cloud timeout

ביצוע

פועלי פעולה: תבני, שלחי, בדקי, לינק, מייל, «תבנו».

  • DELEGATE: id | task
  • Cloud Agent על GitHub
  • מוטציה → PIN (10 דק')
