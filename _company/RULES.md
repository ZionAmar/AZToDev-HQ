# RULES OF THE COMPANY — קיצור מנהלים

## 0) המייסד (ציון) — מודל עבודה
- אתה ↔ **נורה בטלגרם בלבד**
- סוכנים ↔ מדברים **לוקאלית** (`ops/bus/`)
- משימות/דיילי מרחוק ↔ **Linear**
- שומרי סדר: קשת + עמית + נורה (+ אילן בביצוע)
- פירוט: [`OPERATING_MODEL.md`](./OPERATING_MODEL.md)
- מה חסר ממך: [`WHAT_I_NEED_FROM_YOU.md`](./WHAT_I_NEED_FROM_YOU.md)

## 1) נכנס רעיון
טלגרם→נורה או דשבורד → `ops/intake/ideas/` → Intake → Stage Machine (בלי דילוגים) → Linear

## 2) נכנסת בעיה
→ `ops/intake/problems/` → SEV → War-Room או תור; נורה מעדכנת אותך רק אם SEV1/2 או שער

## 3) כל יום
קשת Daily לוקאלי → עמית Day Plan + Linear → ערב: **נורה** שולחת סיכום בטלגרם

## 4) בין הימים
bus לוקאלי; נורה פונה אליך רק לפי אסקלציה / סוף פעולה משמעותית

## 5) דשבורד מקומי + מתג
`EMET-ON.bat` / `EMET-OFF.bat` · http://localhost:8787

## 6) ערוצים חיצוניים
רק נורה→טלגרם אליך; שיווק→סושיאל בשער; כולם לא מקבלים מייל/טלפון למייסד
