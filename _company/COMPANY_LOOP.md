# Company loop — איך העבודה באמת זזה

Cursor Cloud **לא** מחזיק 36 אנשים ערים. הריצה מתה כשהמשימה נגמרת.  
הבית = תיקייה ב-GitHub (`agents/{id}/`). **הדיספצ'ר** (דלפק HQ) הוא מי שמאזין.

```
ציון בטלגרם
  → נועה: מה הבנתי + איך נבצע + מחכה ל«אשר»
  → אחרי אשר: קשת פותחת/מעדכנת Linear (פרויקט אחד, בלי כפילויות)
  → השלב הראשון שצריך דיסק → נדב
       HQ בודק דופק מחשב. אף פעם לא שואלים את ציון «המחשב דולק?»
       כבוי = תור. דולק = רץ.
  → צריך סיסמה → אומרים מיד. אם אין תגובה — תזכורת כל ~8 דקות
  → אחרי סיסמה: ממשיכים את אותה משימה, בלי לבקש ממנו לחזור על הכל
  → מי שסיים כותב outbox + DELEGATE הבא. HQ מעיר את הבא
  → נועה מקבלת עדכון לטלגרם. Linear מתעדכן
```

## תיקיות (סגנון תום אבן)

| מקום | תפקיד |
|------|--------|
| `agents/{id}/inbox/` | מטלה שנשפכה — הדיספצ'ר מעיר |
| `agents/{id}/outbox/` | תוצאה + ראיות |
| `agents/{id}/memory/learning-log.md` | לקחים בין ריצות |
| Linear | סטטוס שציון רואה מהטלפון |

## אסור

- לפתוח שוב את אותו טיקט תחת שם אחר (KNG / KG / KNU במקביל)
- לשאול אם המחשב דולק
- להיתקע אחרי סיסמה בלי להמשיך
- להעמיד פנים ששיחת `bc-…` היא אדם חי
