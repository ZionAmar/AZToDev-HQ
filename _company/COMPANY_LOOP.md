# Company loop — איך העבודה באמת זזה

Cursor Cloud **לא** מחזיק 36 אנשים ערים. הריצה מתה כשהמשימה נגמרת.  
הבית = תיקייה ב-GitHub (`agents/{id}/`). **הדיספצ'ר** (דלפק HQ) הוא מי שמאזין.

```
ציון בטלגרם
  → נועה: מה הבנתי + איך נבצע + מחכה ל«אשר»
  → אחרי אשר: קשת פותחת/מעדכנת Linear (פרויקט אחד, בלי כפילויות)
  → השלב הראשון שצריך דיסק → נדב
       HQ בודק דופק מחשב. אף פעם לא שואלים את ציון «המחשב דולק?»
       כבוי = תור. דולק = רץ.
  → צריך סיסמה → אומרים מיד. אם אין תגובה — תזכורת כל ~8 דקות
  → אחרי סיסמה: ממשיכים את אותה משימה, בלי לבקש ממנו לחזור על הכל
  → מי שסיים כותב outbox + DELEGATE הבא. HQ מעיר את הבא
  → נועה מקבלת כל עדכון ממומחה. היא מטריאז'ת: תקלה→מטפלת; צריך ציון (סיסמה/אשר)→מודיעה; סיים→מעבירה לשלב הבא
  → משימה פתוחה ב-factory.activeWork בלי סיום: נועה מטרידה כל ~8 דקות עם **התקלה באמצע** — אסור שקט
```

## סטטוס חי

«סטטוס» בדלפק = תשובה מיידית בלי לחכות לנועה:

| שורה | משמעות |
|------|--------|
| זרימה | המשימה הפתוחה במפעל + שלב + בעלים |
| עכשיו | מי רץ + קישור `https://cursor.com/agents/…` |
| מחכה ל | סיסמה / «אשר» / מחשב כבוי / מומחה בתור — **בדיוק** למה |
| הבא | מי בתור או מה הצעד אחרי השער |

כל הודעת מומחה עוברת בנועה. ציון לא מקבל dump. אם צריך אותו — היא אומרת מה בדיוק.

## תיקיות (סגנון תום אבן)

| מקום | תפקיד |
|------|--------|
| `agents/{id}/inbox/` | מטלה שנשפכה — הדיספצ'ר מעיר |
| `agents/{id}/outbox/` | תוצאה + ראיות |
| `agents/{id}/memory/learning-log.md` | לקחים בין ריצות |
| Linear | סטטוס שציון רואה מהטלפון |

## אסור

- לפתוח שוב את אותו טיקט תחת שם אחר (KNG / KG / KNU במקביל)
- לשאול אם המחשב דולק
- להפעיל את תמיר / לסרוק את השרת בלי שציון ביקש במפורש לבדוק שרת
- להריץ כמה מומחים במקביל על אותה משימה
- להיתקע אחרי סיסמה בלי להמשיך
- להשאיר activeWork פתוח בלי waitingFor ובלי נגיסה
- לסגור שלב רק בטלגרם בלי לכתוב אותו ל-board/ledger/outbox באותה נשימה — ריצת Cloud יכולה להיעלם בכל רגע, ומה שלא נכתב לקובץ לא שרד. ראו `_company/handbook/failure-handling.md` § Cloud-run timeouts
- לבקש שוב אישור/סקירה שכבר מסומן done ב-board או ב-ledger — שלוש בקשות חזרה על אותו שלב = כשל תהליך, לא ניסיון חוזר
- להעמיד פנים ששיחת `bc-…` היא אדם חי
