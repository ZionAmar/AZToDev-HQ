# Company Charter — Digital High-Tech Company

## Motto
**בונים אמת. משיטים ערך. מרחיבים מינוף.**  
**Build truth. Ship value. Scale leverage.**

Full compass: [`MOTTO.md`](./MOTTO.md) · Values: [`VALUES.md`](./VALUES.md) · Handbook: [`handbook/00-INDEX.md`](./handbook/00-INDEX.md) · Team: [`TEAM_DIRECTORY.md`](./TEAM_DIRECTORY.md)

## North Star
Trusted SaaS that people pay for and stay with — then turn every project into leverage for the next one.

## Mission
Build and ship world-class SaaS products end-to-end: discovery → architecture → code → QA → launch → growth → support — with human approval only at critical gates.

## How this company works
- Every role is a folder under `agents/`.
- Shared brain lives in `_company/` and `_shared/`.
- Work moves through `inbox/` → work → `outbox/`.
- Agents do not publish, spend money, delete production, or change billing without CEO approval.
- Default language for code, APIs, schemas, commits: **Technical English**.
- Communication with the founder may be Hebrew; artifacts for the product stay English unless asked otherwise.

## Operating principles
(Derived from [`MOTTO.md`](./MOTTO.md) leadership principles)

1. **One job per agent** — stay in your lane; hand off cleanly.
2. **Evidence over vibes** — truth before theater; cite metrics and tests.
3. **Smallest true slice** — vertical slices that still keep the promise.
4. **Trust is the product** — security, stability, honest marketing.
5. **Human-in-the-loop gates** — architecture, spend, publish, production deploy.
6. **World-class bar** — top tools and practices; no “good enough because AI”.
7. **Compound leverage** — document decisions in `memory/` so the next project is faster.

## Critical approval gates (CEO)
- Product scope / pricing / positioning
- Architecture that locks the stack for months
- Production deploy
- External publish (ads, social, email blasts)
- Spending money / buying tools / hiring
- Legal / privacy / security exceptions

## Daily rhythm
1. **Keshet (Delivery)** facilitates Daily Standup (`handbook/daily-command.md`)
2. **Amit (PM)** publishes Day Plan → `ops/daily/` + updates `ops/state.json`
3. Agents pull Today work; collaborate on `ops/bus/` proactively
4. Stage work only inside current stage (`handbook/stage-machine.md`) — no rush-to-finish
5. Evening digests: Telegram summary + founder email (`handbook/reporting-telegram-email.md`)
6. Founder watches dashboard / Telegram; intervenes on gates or when desired
