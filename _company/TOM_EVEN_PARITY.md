# Tom Even Parity+ — הרף שלנו

אנחנו לא מעתיקים Obsidian. אנחנו שואפים **לאותה תחושת חברה חיה** — ועולים מעליה במה שחשוב לך: **מוצרי SaaS אמיתיים**.

## מה תום אבן נותן (הרף)
| יכולת | אצלו | אצלנו (יעד) |
|--------|------|-------------|
| סוכנים עם זהות ותפקיד | פתקים + prompts | 33 סוכנים + אישיות + training |
| שיחה בין סוכנים | קבצים משותפים | `ops/bus/` + ישיבות מתוזמרות |
| אתה מנהל מרחוק | ממשקים שלו | **נעה בטלגרם** + Linear בטלפון |
| אוטומציות יומיות | דיילי / שגרות | Daily + סיכום ערב אוטומטי |
| תוצרים | בעיקר תוכן/אופרציה | **קוד + מוצר** דרך Cursor לוקאלי |
| משמעת | תלוי בהגדרות | Stage Machine + שומרי סדר (קים/יונתן/נעה) |
| כיבוי/המשך | מחשב דולק | **ON/OFF + checkpoint** |

## מה אצלנו חייב להיות “לא פחות”
1. שיחה חופשית איתך (טלגרם ↔ נעה)
2. סוכנים שממשיכים לבד בין הסיכומים
3. ישיבות אמיתיות (Intake/Daily/Shape…) עם החלטות כתובות
4. זיכרון משותף חי
5. סיכום סוף יום + אחרי פעולה משמעותית
6. ניהול עדיפויות גם בהצפת רעיונות

## מה אצלנו חייב להיות **יותר טוב**
1. בניית SaaS אמיתית (Cursor מקומי, לא העתקת קוד מפתק)
2. שערי איכות (לא לרוץ לסוף)
3. מתג חשמל + resume מדויק
4. ראייה מהטלפון בלי הצפת 30 סוכנים (Linear + נעה)
5. Least privilege — לא לכל אחד כרטיס אשראי/סושיאל
