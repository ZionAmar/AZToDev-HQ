# מה צריך ממך

רוב החיבורים כבר ב-`.env`. לא להדביק מפתחות בצ׳אט.

| חיבור | סטטוס |
|--------|--------|
| Cursor | חי — Cloud **לא** רץ על מוצר עד פקודה |
| GitHub דרך Cursor | רשימת ריפואים חיה |
| Telegram | חי — כשה-HQ דולק |
| Linear | חי — כרטיס הקמה [EMET-65](https://linear.app/my-company1460/issue/EMET-65) |
| Gmail | חי |
| OpenAI | חי |
| Gemini | חסר — אם יש, שים `GEMINI_API_KEY` ב-`.env` (לא כאן) |
| ChemiCloud | חסר — IP + משתמש SSH כדי שנורה תחיה כשהמחשב כבוי |
| סושיאל | חסר — אסמונות מדיה כשתרצה שהמשווק יפרסם |

**לא צריך ריפו עכשיו.** ציון ביקש הקמת חברה בלבד.
