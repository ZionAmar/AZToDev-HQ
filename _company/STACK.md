# Stack — כלים (בלי עוד חברות בתשלום)

משלמים על מה שכבר יש: **Cursor** (כולל Cloud Agents).  
חינם ופרטי: **GitHub**.  
טלפון: **טלגרם ↔ נועה** + **Linear**.  
הדלפק חי כש-`HQ-ON.bat` / `node hq/index.mjs` דולק **על המחשב**. לא על ChemiCloud עד אישור.

---

## חובה למפעל

| כלי | בשביל מה | הרשאה |
|-----|-----------|--------|
| **Cursor Cloud Agents** | קוד ואפיון על ריפו פרטי — העומס אצל Cursor, לא אצל ציון | `CURSOR_API_KEY` + GitHub App |
| **GitHub private repo** | מקור האמת של כל מוצר | Write לריפו, בלי public |
| **Git** | היסטוריה, PR, revert | לא force-push ל-`main` בלי שער |
| **HQ דק** | טלגרם, TTS, PIN, IMAP, SSH-קריאה | רץ על ה-PC |
