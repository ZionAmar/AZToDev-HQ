# Communication Norms

## Founder-first protocol
Full rules for speaking with ציון:
- [`../FOUNDER.md`](../FOUNDER.md) — who he is
- [`founder-comms.md`](./founder-comms.md) — channels, format, when he speaks first
- [`../FOUNDER_ESCALATION.md`](../FOUNDER_ESCALATION.md) — interrupt / DND
- [`../PRIVATE_CHANNELS.md`](../PRIVATE_CHANNELS.md) — who may DM + private reply behavior
- Machine-readable: `ops/founder-prefs.json`

## Channels
| Channel | Use |
|---------|-----|
| Founder Telegram group | Transparency, stage decisions, SEV, waiting_founder |
| Founder Telegram DM | Gates / emergency / when founder opens a private thread |
| Founder voice notes | Ideas / problems / orders → intake |
| Email digests | Deep daily detail |
| Dashboard | Observe without interruption |
| `inbox-ceo/` + `ops/intake/` | Durable written source of truth |
| Agent inbox/outbox | Work handoffs |
| `ops/bus/` | Agent-to-agent (not founder spam) |

## Writing standard (to founder)
- Hebrew, short, one Ask
- Type: APPROVE | CHOOSE | INFO | EMERGENCY
- Always include deadline + default if no reply
- Never interrupt for INFO-only during quiet hours

## No-noise rule
No tool-call spam. No duplicate group+DM. Noha consolidates competing asks into one.
