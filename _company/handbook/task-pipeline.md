# צינור משימות — עברית, סטטוס, אישור אחרי כל משימה

## הזרימה
1. סוכן מבצע משימה מהלוח (עברית)
2. מעדכן **סטטוס** בלוח המקומי (+ Linear אם מחובר)
3. שולח לציון:
   - הודעת טקסט בטלגרם
   - **דוח קולי** מוקלט
   - **מייל מעוצב** ל־aztodev@gmail.com
4. **עוצרים** — ממתינים ל־APPROVE
5. ציון כותב «כן» / «המשך» / «אשר» → מתחילים אוטומטית את המשימה הבאה

## סטטוסים
