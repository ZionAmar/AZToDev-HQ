# Telegram = שיחת Cursor עם נורה

## המודל
כל הודעה שלך בטלגרם נכנסת **ישירות** לחלון Cursor המתמשך של נורה ב־`agents/00-ceo`.
כמו לכתוב לה כאן באייג'נט — בלי מסלולים, בלי תיאטרון.

## פקודות
| מה | מה קורה |
|----|---------|
| טקסט חופשי | נכנס לשיחה שלה; היא עונה / עובדת |
| «סטטוס» / `/status` / «מה קורה» | תשובה **מיידית** מהדלפק: זרימה · עכשיו (עם קישור לאייג'נט) · מחכה ל־מה בדיוק · השלב הבא |
| «שיחה חדשה» / `/new` / `/start` | מאפסת את חלון Cursor שלה |

## שקיפות (חוק מייסד)
- אסור שקט ארוך בלי משוב: soft-ack, progress כל ~90 שנ׳, ובהודעת timeout ברורה.
- שקיפות: כל עדכון ממומחה עובר בנועה — תקלה היא מטפלת; אם צריך את ציון היא אומרת; אם עבר שלב היא אומרת מה הבא. בלי לוג גולמי.
- Docker Desktop לא נפתח סתם — רק אם אישרת במפורש למשימה שדורשת containers.

## יומן מרכזי (חובה)
כל הודעה בטלגרם — של ציון, של נועה, ושל עדכוני רקע ממומחים (נדב וכו') — נרשמת ב־`ops/founder-channel/ledger.jsonl` (ב־Git).
Cloud Noa קורא את זה לפני סטטוס/delegate. אסור לפתוח מחדש שלב שכבר מופיע ביומן.

## בין סוכנים
כשנורה (או סוכן אחר) קוראים ל־`emet_delegate` — נפתח/ממשיך **חלון Cursor אמיתי** בתיקיית הסוכן.
הם עובדים עם כלים, מחזירים תוצאה. מוצרים אמיתיים תחת `products/`.

**מנדט מייסד:** נורה **לא** עושה בעצמה עבודה של מומחים (קוד, QA, עיצוב וכו'). רק delegate + אימות artifact.
מדיניות: `_company/DELEGATION_POLICY.md`
