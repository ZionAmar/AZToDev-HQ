# AZTODEV Dashboard

תמצית חיה של מה שהחברה קבעה ומה קורה עכשיו.

## הרצה
מתיקיית `my_company`:

```bash
node dashboard/server.mjs
```

פתח: http://localhost:8787

## מה רואים
- ממתינים לאישור המייסד
- תוכנית היום / מה לא עושים
- מה כל סוכן עושה עכשיו
- יוזמות לפי Stage (בלי לרוץ לסוף)
- החלטות וישיבות אחרונות

מקור האמת: `ops/state.json`
